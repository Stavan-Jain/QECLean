# Parked: the second de-nativization wave

This branch preserves five formalizations removed from the line heading to
`main` so that `main` can reach a **`native_decide`-free** state. They were
removed together in `refactor: park every remaining native_decide
formalization`; before that removal the tree had 35 `native_decide` tactic
sites, and after it, zero.

The first wave is `Z3Z6/` — see [`QEC/Stabilizer/Codes/BivariateBicycle/Z3Z6/PARKED.md`](QEC/Stabilizer/Codes/BivariateBicycle/Z3Z6/PARKED.md),
which also records the techniques the gross PR #66 conversion established.
This file covers everything else.

  `witness*_weight`, `*_comm`, `*z*_comm`, `*_anti_*_symp`. These are small

## Restoring one

All six are clean leaves — nothing outside each directory imported their
declarations. To bring one back:

1. Restore the directory (or file) and its sibling umbrella.
2. Re-add the import line to the parent umbrella: `BivariateBicycle.lean`,
   `Codes.lean` (for `Concat`), `RotatedSurface.lean`, or `Small.lean`.
3. Restore the rows removed from
   `QEC/Stabilizer/Codes/BivariateBicycle/README.md` § "Parked instances"
   and the note in `CLAUDE.md`.
4. `bash scripts/check-umbrellas.sh`, then `lake build`.

## Build-cost note

Do **not** use "the Gross cone is slow" as a reason to avoid rebuilding.
Measured on a 16 GB machine: the whole repo builds in **~44 s** including a
full Gross cone rebuild. An earlier apparent 13-minute stall on
`SafeFloor/MImFloorY{0,1,4}.lean` was memory thrashing, not proof cost —
`lake` (4.30.0-rc2, which has no `-j` flag) schedules those three
concurrently and their combined working set exceeded RAM, driving 8 GB into
the compressor and stalling the workers at 4–10% CPU. Built alone,
`MImFloorY0` takes **40 s**. If a build appears to hang there, check
`top` for compressor/swap growth before assuming a proof regressed.
